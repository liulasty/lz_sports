# frontend-design Examples

Use these prompts to trigger this skill reliably.

## Example 1: Landing Page

**User prompt**
Build a premium brand landing page for a new electric motorcycle with bold typography and cinematic motion.

**Expected behavior**
- Picks a clear aesthetic direction (e.g., industrial-luxury, dark tone)
- Uses distinctive font pairing instead of generic defaults
- Builds real HTML/CSS/JS (or framework code) with production-ready structure
- Adds meaningful motion for load, hover, and scroll moments

## Example 2: Dashboard UI

**User prompt**
Design a sports analytics dashboard in React, with an editorial magazine style and strong visual hierarchy.

**Expected behavior**
- Commits to one coherent editorial visual language
- Uses asymmetrical layout and strong spacing rhythm
- Applies reusable design tokens via CSS variables
- Implements accessible and responsive components

## Example 3: Component Beautification

**User prompt**
Refactor and beautify this existing card component. Keep functionality unchanged, but make it unforgettable.

**Expected behavior**
- Preserves behavior and API compatibility
- Upgrades typography, color system, and interaction details
- Avoids common AI-generic styles (Inter + purple gradient patterns)
- Delivers polished, maintainable code

## Example 4: Marketing Poster

**User prompt**
Create a single-page web poster for a campus marathon registration campaign, playful but sharp, mobile-first.

**Expected behavior**
- Chooses a playful yet intentional style direction
- Uses dramatic composition and memorable hero section
- Adds lightweight animation and clear CTA behavior
- Ensures mobile-first responsiveness and readable contrast
