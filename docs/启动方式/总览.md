# LZ Sports 启动方式总览

本项目提供了一套高度工程化的全栈启动与部署方案，支持通过统一的跨平台脚本进行一键构建、测试与部署。无论你是前端开发、后端开发，还是运维人员，都能找到最适合当前场景的启动模式。

## 🚀 核心启动脚本 (`scripts/`)

我们在项目根目录的 `scripts/` 下提供了 Windows (`.bat`) 和 Linux/macOS (`.sh`) 的对等启动脚本。

所有环境切换、配置注入、组件依赖等复杂逻辑均已封装在脚本中，你只需要：
1. **编译构建**：`build.bat` / `build.sh`
2. **一键部署**：`deploy.bat` / `deploy.sh`

### 脚本参数速查表

部署脚本 `deploy` 支持自由组合以下参数：

| 参数类型 | 可选值 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| **环境** | `dev` (默认)<br>`prod` | `dev` 会暴露基础设施端口(3306,6379)，内存限制宽泛。<br>`prod` 不暴露内部端口，内存控制严格，带宕机重启。 | `deploy.bat prod` |
| **基础设施** | `--local-db` | 核心参数！如果带上此标志，Docker 不会启动容器化的 MySQL 和 Redis，而是让容器内的后端直连你宿主机本地的数据库。 | `deploy.bat dev --local-db` |
| **版本号** | 任意字符串 (默认 `latest`) | 指定要启动或构建的镜像版本。 | `deploy.bat prod v1.0.0` |

## 🛠 启动场景指南

请根据你的实际身份和需求，选择对应的详细启动文档：

### 0. 纯本地联调（当前推荐）
如果你已经具备本地 MySQL/Redis，并希望不依赖 Docker 进行前后端联调：
* 👉 **[Windows 本地联调统一指南](./本地开发/本地联调统一指南.md)**

### 1. 容器化一键部署（推荐测试/运维使用）
如果你不需要修改代码，只想快速拉起整个系统（前端 + 后端 + 数据库 + 缓存）：
* 👉 **[Windows 桌面版 Docker 部署指南](./容器部署/DockerDesktop.md)**
* 👉 **[Linux 服务器生产环境部署指南](./容器部署/LinuxDocker.md)**

### 2. 混合模式开发（推荐前后端开发者使用）
借助 `--local-db` 标志，你可以实现“半容器化”开发。
* **后端开发者**：可以使用 `deploy.bat dev` 启动全套基础设施和前端，然后在 IDEA 中以 Debug 模式启动后端代码进行断点调试。
* **前端开发者**：可以使用 `deploy.bat dev` 启动后端、数据库和缓存，然后在本地通过 `npm run dev` 启动 Vue 进行开发热更新。
* 👉 **[Windows 混合开发指南](./本地开发/Windows本地.md)**
* 👉 **[Linux/macOS 混合开发指南](./本地开发/Linux本地.md)**

## ⚙️ 配置文件结构说明

项目的环境配置完全实现了**代码与配置解耦**，你无需修改任何代码或 Spring Boot/Vue 的内部配置文件，所有的控制枢纽都在 `config/` 目录下：

* `config/.env.dev`：开发环境配置文件。管理数据库账号密码、端口暴露、JWT密钥等。
* `config/.env.prod`：生产环境配置文件。

> 💡 **进阶提示**：如果你需要修改默认运行的端口（例如 8080 被占用），请直接查阅 **[端口切换配置指南](./端口切换配置指南.md)**，只需修改一行配置即可全局生效。
