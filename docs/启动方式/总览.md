# LZ Sports 启动方式总览

本文档将运行方式拆分为四个独立文档，统一采用 `FRONTEND_PORT` 控制前端端口，便于在不同环境保持一致或按环境差异化配置。

## 四种启动方式

- Windows 本地启动（前后端都本地运行）  
  见：`docs/启动方式/本地开发/Windows本地.md`
- Linux 本地启动（前后端都本地运行）  
  见：`docs/启动方式/本地开发/Linux本地.md`
- Docker Desktop 启动（Windows 容器编排）  
  见：`docs/启动方式/容器部署/DockerDesktop.md`
- Linux Docker 启动（Linux 容器编排）  
  见：`docs/启动方式/容器部署/LinuxDocker.md`

## 统一端口策略

- 前端统一变量：`FRONTEND_PORT`
- 默认值：`5173`
- 生效范围：
  - 前端本地开发（Vite）
  - 前端 Docker 镜像（Nginx listen 与 EXPOSE）
  - Docker Compose 端口映射

## 推荐端口规划

- 统一模式：四种方式都用 `5173`
- 区分模式（示例）：
  - Windows 本地：`5173`
  - Docker Desktop：`5180`
  - Linux 本地：`5174`
  - Linux Docker：`5190`
