# LZ Sports 端口切换配置指南

在日常开发或部署过程中，如果默认的前端端口（`5173`）或后端端口（`8080`）被占用，或者需要部署多个实例，可以通过修改以下配置来进行端口切换。

---

## 一、 前端端口修改（默认 5173）

前端的端口配置统一由环境变量 `FRONTEND_PORT` 进行管理，修改起来比较简单。

### 1. 本地开发环境 (Vite)
* **修改环境变量**：
  在 `lz_sports_frontend/.env`（或 `.env.development`）中，添加或修改：
  ```env
  FRONTEND_PORT=你的新前端端口
  ```
  *(注：`lz_sports_frontend/vite.config.js` 会自动读取该变量作为启动端口)*

### 2. Docker 部署环境
* **修改环境变量**：
  在项目**根目录**的 `.env` 文件中，添加或修改：
  ```env
  FRONTEND_PORT=你的新前端端口
  ```
* **工作原理**：
  * `docker-compose.yml` 中会自动读取此变量映射端口：`"${FRONTEND_PORT:-5173}:${FRONTEND_PORT:-5173}"`
  * `lz_sports_frontend/Dockerfile` 中会接收此参数，通过 `sed` 动态替换 `nginx.conf` 的监听端口：`RUN sed -i "s/listen 80;/listen ${FRONTEND_PORT};/" /etc/nginx/conf.d/default.conf`

---

## 二、 后端端口修改（默认 8080）

后端的端口修改分为**仅修改宿主机映射端口**和**全面修改容器内外端口**两种情况。**强烈建议在 Docker 环境下仅修改宿主机映射端口**。

### 1. 仅修改宿主机暴露端口（推荐 Docker 部署使用）
如果只是为了避免宿主机端口冲突，后端容器内部仍然保持 `8080` 运行。
* **文件**：`docker-compose.yml`
* **操作**：找到 `backend` 服务，修改 `ports` 映射（左侧为宿主机端口，右侧为容器内端口）：
  ```yaml
  backend:
    ports:
      - "你的新后端端口:8080"  # 例如 "9090:8080"
  ```
* **注意**：这种方式**不需要**修改前端 Nginx 的反向代理配置，因为容器间通过 Docker 内部网络通信，仍然访问 `http://backend:8080/api/`。

### 2. 彻底修改后端端口（本地开发或必须修改内部端口时）
如果你在本地运行（不使用 Docker），或者必须彻底更改 Spring Boot 服务的运行端口，需要同步修改前后端相关的配置。

**步骤 A：修改后端服务端口**
* **文件**：`lz_sports_backend/src/main/resources/application.yml` （或对应的环境配置如 `application-dev.yml`）
* **操作**：
  ```yaml
  server:
    port: 你的新后端端口  # 例如 9090
  ```
  *(或者在 `lz_sports_backend/.env` 中配置 `SERVER_PORT=你的新后端端口`)*

**步骤 B：修改本地前端代理 (仅限本地开发)**
* **文件**：`lz_sports_frontend/vite.config.js`
* **操作**：将 target 端口改为新的后端端口：
  ```javascript
  proxy: {
    '/api': {
      target: 'http://localhost:你的新后端端口', // 例如 http://localhost:9090
      changeOrigin: true
    }
  }
  ```

**步骤 C：修改 Docker 部署配置 (如果也使用 Docker)**
1. 修改 `docker-compose.yml` 中的映射：
   ```yaml
   backend:
     ports:
       - "你的新后端端口:你的新后端端口" # 例如 "9090:9090"
   ```
2. 修改前端 Nginx 的反向代理地址：
   * **文件**：`lz_sports_frontend/nginx.conf`
   * **操作**：将 `proxy_pass` 中的端口改为新端口：
     ```nginx
     location /api/ {
         proxy_pass http://backend:你的新后端端口/api/; # 例如 http://backend:9090/api/
         # ... 其他配置保持不变
     }
     ```

---

## 💡 总结与建议

1. **前端**：全系统一由 `FRONTEND_PORT` 环境变量控制，直接改 `.env` 即可。
2. **后端 (本地)**：改 `application.yml` 中的 `server.port` + 前端 `vite.config.js` 中的 `proxy`。
3. **后端 (Docker)**：优先只改 `docker-compose.yml` 中的宿主机映射端口（如 `"9090:8080"`），这样不需要动前端 Nginx 配置。
