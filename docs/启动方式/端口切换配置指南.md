# 端口冲突与切换指南

在开发或部署过程中，如果遇到“端口被占用 (port is already allocated)”的错误，你需要更改服务对应的映射端口。

由于本项目的架构已经实现了高度的配置统一，你**不需要修改代码**，只需修改对应的环境变量文件即可全局生效。

## 🎯 核心控制文件

所有的端口定义都集中在以下两个文件中：
- 开发环境：`config/.env.dev`
- 生产环境：`config/.env.prod`

## 🛠 如何修改端口

请打开你当前使用的 `.env` 文件，找到你想修改的端口号，修改后重新运行部署脚本（如 `deploy.bat dev`）即可。

### 1. 前端端口被占用 (默认 5173 / 80)
```env
# 找到这一行
FRONTEND_PORT=5173

# 修改为你想要的端口，例如：
FRONTEND_PORT=3000
```
*(注意：生产环境 `.env.prod` 中前端端口默认为 `80`，如果你的服务器上 80 端口已经被 Nginx 或 Apache 占用，请修改它，例如改为 `8080`)*

### 2. 后端端口被占用 (默认 8080)
```env
# 找到这一行
BACKEND_PORT=8080

# 修改为你想要的端口，例如：
BACKEND_PORT=9090
```
> **自动级联**：得益于我们的架构设计，当你修改了 `BACKEND_PORT` 后，前端 Docker 容器中的 Nginx 反向代理配置会自动更新，去找你新修改的后端端口，你无需手动去改前端代码里的 `VITE_API_BASE_URL`！

### 3. MySQL 端口被占用 (默认 3306)
如果你的电脑上自己安装了一个 MySQL 正在运行，它占用了 3306，你可以修改 Docker 中 MySQL 映射出来的端口。

```env
# 找到这一行
DB_PORT=3306

# 修改为，例如：
DB_PORT=3307
```
*(修改后，你可以通过 `localhost:3307` 连接到 Docker 里的 MySQL，同时后端的 Spring Boot 也会自动去连 `3307`)*

### 4. Redis 端口被占用 (默认 6379)
```env
# 找到这一行
REDIS_PORT=6379

# 修改为，例如：
REDIS_PORT=6380
```

### 5. 数据库管理面板 Adminer 端口冲突 (默认 8081)
```env
# 找到这一行
ADMINER_PORT=8081

# 修改为，例如：
ADMINER_PORT=8082
```

## 🔄 生效修改

修改保存后，直接执行一键部署脚本重启服务即可。Docker 会自动销毁旧容器并使用新端口创建新容器。

```bat
# Windows 示例
.\scripts\deploy.bat dev
```
