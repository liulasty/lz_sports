# Phase 3 自检清单 · 成绩与通知

> 全部为 [x] 才允许进入 Phase 4

---

## 🏅 成绩录入

- [ ] 只能为 CONFIRMED 状态的报名录入成绩，其他状态返回 409
- [ ] 重复录入同一报名的成绩时执行更新（upsert，不报错）
- [ ] 已发布的成绩不可修改，返回 409
- [ ] 草稿成绩通过用户侧接口查询时不返回
- [ ] result 表的 item_registration_id 有唯一索引（一条报名一条成绩）

---

## 📢 成绩发布

- [ ] 发布后 is_published 置为 1，published_at 记录发布时间
- [ ] 发布后成绩不可修改（Service 层拦截）
- [ ] 发布后异步向该赛事所有运动员发站内通知
- [ ] 发布操作不可撤回（无撤回接口）
- [ ] 前端发布前弹出二次确认弹窗，用户点确认才执行

---

## 📊 Excel 导入

- [ ] 下载模板接口正确生成含已通过报名数据的 Excel
- [ ] 导入时逐行校验：
  - [ ] 报名ID是否存在且属于该赛事
  - [ ] 报名状态是否为 CONFIRMED
  - [ ] 成绩字段是否为空
  - [ ] 该成绩是否已发布（已发布不可覆盖）
- [ ] 部分行失败时其他行正常导入（不因一行失败回滚全部）
- [ ] 导入结果返回：成功N条、失败N条、失败详情（行号+原因）
- [ ] 上传文件大小限制 ≤ 10MB，超出返回 400

---

## 📤 Excel 导出

- [ ] 导出成绩表按项目分 Sheet
- [ ] 导出报名名单包含：序号、姓名、院系、年级、项目、报名时间、状态
- [ ] 导出成绩表包含：排名、姓名、院系、年级、成绩、备注
- [ ] 导出文件名包含赛事名称和导出时间
- [ ] 导出响应头正确设置（Content-Disposition、Content-Type）

## 🔔 站内信

- [ ] 发送通知时 sys_user.unread_count + 1（原子 UPDATE）
- [ ] 标记单条已读时 unread_count - 1
- [ ] 全部标记已读时 unread_count 直接置为 0
- [ ] 只能标记自己的通知，标记他人通知返回 403
- [ ] 未读消息数量接口直接读取 unread_count 字段（不实时统计）
- [ ] 批量发送通知（赛事发布/成绩发布）使用异步 @Async
- [ ] 以下场景全部触发通知：
  - [ ] 赛事发布 → 所有注册用户
  - [ ] 运动员申请通过 → 申请人
  - [ ] 运动员申请拒绝 → 申请人（含原因）
  - [ ] 成绩发布 → 该赛事所有运动员
