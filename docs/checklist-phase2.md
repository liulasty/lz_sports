# Phase 2 自检清单 · 赛事核心

> 全部为 [x] 才允许进入 Phase 3

---

## 📅 赛事管理

- [ ] 创建赛事时间校验：regStart < regEnd < eventStart < eventEnd
- [ ] 创建赛事 maxItemsPerAthlete 必填，范围 1-20
- [x] 赛事创建后状态为 DRAFT
- [ ] 发布赛事前校验：至少有一个 event_item，否则 400
- [ ] 发布赛事前校验：至少有一个赛事管理员，否则 400
- [ ] 发布成功后异步向所有注册用户发站内通知
- [ ] 撤回赛事：仅 OPEN 且当前时间 < regStartTime 时可撤回
- [ ] 草稿赛事通过公开接口访问返回 404
- [ ] 删除赛事：仅 DRAFT 状态可删，同时删除关联 event_item 和绑定关系

---

## ⏱️ 定时任务

- [ ] EventStatusScheduler 每分钟执行一次
- [ ] OPEN + 当前时间 > reg_end_time → 自动变 CLOSED
- [ ] CLOSED + 当前时间 > event_start_time → 自动变 ONGOING
- [ ] ONGOING + 当前时间 > event_end_time → 自动变 FINISHED
- [ ] 定时任务失败时有日志记录，不影响主流程

---

## 🏃 项目库

- [ ] category = STANDARD 的项目删除时返回 403
- [ ] 有赛事正在使用的项目删除时返回 409
- [ ] 新建赛事项目时校验 itemStartTime 在赛事时间范围内
- [ ] 有报名记录的赛事项目删除时返回 409，提示已有X人报名

## 🎽 运动员申请

- [ ] 赛事状态不是 OPEN 时申请返回 409
- [ ] 同一用户同一赛事重复申请返回 409
- [ ] 申请成功后自动同步 realName/department/grade/phone 到 sys_user（方案C）
- [ ] SUPER_ADMIN 和 EVENT_ADMIN 角色不可申请，返回 403
- [ ] 审核通过后异步发送站内通知
- [ ] 审核拒绝后异步发送站内通知（含拒绝原因）
- [ ] 已审核的申请重复审核返回 409
- [ ] 批量审核只处理 PENDING 状态，已审核的跳过并在结果中说明

## 📝 项目报名（7项校验逐一验证）

- [ ] 校验1：账号 DISABLED 时返回「账号已被禁用」

- [x] 校验3：不在报名时间内返回「不在报名时间范围内」
- [x] 校验4：名额已满返回「该项目报名人数已满」
- [x] 校验5：重复报名同一项目返回「您已报名该项目，请勿重复报名」
