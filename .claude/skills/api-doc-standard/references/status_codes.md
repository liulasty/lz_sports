# Status Codes

## HTTP Status Codes
- **200 OK**: 请求成功。
- **400 Bad Request**: 请求参数错误。
- **401 Unauthorized**: 未授权，请登录。
- **403 Forbidden**: 无权限访问。
- **404 Not Found**: 资源不存在。
- **500 Internal Server Error**: 服务器内部错误。

## Business Error Codes (Example)
| Code | Message | Description |
| :--- | :--- | :--- |
| 0 | success | 成功 |
| 1001 | invalid_param | 参数无效 |
| 1002 | resource_not_found | 资源未找到 |
| 2001 | auth_failed | 认证失败 |
